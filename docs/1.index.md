# Curio

A curious way to query Eloquent — turn a single query string into filtering, sorting, eager loading, column selection, aggregation, casting and pagination, with validation baked in.

```
GET /api/posts?filter=title:*laravel* published_at:>=2025-01-01&sort=-published_at&include=author comments:@count&page=1&size=25
```

Every endpoint is built from three pieces:

- A [`PaginateQuery`](/reference) subclass declares what's allowed — which fields can be filtered, sorted, included, aggregated, or cast.
- A `FormRequest` uses the `PaginateRequest` trait, wiring it to a `PaginateQuery` and exposing a `paginate(Builder $builder)` method.
- A controller calls `$request->paginate($builder)` and returns the result — a standard `LengthAwarePaginator`.

Everything on top of that — parsing the query string, validating it against what the `PaginateQuery` allows, and applying it to the Eloquent builder — is handled for you.

## Requirements

- PHP `^8.4`
- Laravel `^12.0 || ^13.0` — Curio targets a full Laravel application, not the standalone Illuminate components: `PaginateRequest` builds on `Illuminate\Foundation\Http\FormRequest`, which only ships with `laravel/framework`.
