# Cookbook

Every example in this section comes from this package's own test fixtures (`workbench/`) — a small blog domain used end-to-end by the test suite, so every snippet shown is real, tested code, not illustrative pseudocode.

## The domain

```
Author
├── hasMany   Post      (author_id)
├── hasMany   Comment   (author_id)
└── hasOne    latestPost   — Post, ordered ->latest()

Post
├── belongsTo Author    (author_id)
└── hasMany   Comment   (post_id)

Comment
├── belongsTo Author    (author_id)
└── belongsTo Post      (post_id)

User   — bare Eloquent model, no relations to the above
```

Each model has a matching `PaginateQuery`, `FormRequest`, controller, and Resource, all registered under `GET /api/{author,post,comment,user}`.
