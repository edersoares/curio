# Search and ranking tiers

The `Author` endpoint (`GET /api/author`) demonstrates [free-text search](/query-string/searching), [casting](/query-string/casting), and sorting by a `hasOne` relation column.

```php
class AuthorQuery extends PaginateQuery
{
    public function includeBy(): array
    {
        return [
            'posts' => PostQuery::class,
            'comments' => CommentQuery::class,
        ];
    }

    public function filterBy(): array
    {
        return [
            'name' => ['string'],
            'title' => ['string'],
            'email' => ['string'],
            'date_of_birth' => ['date', 'after_or_equal:1990-01-01', 'before_or_equal:2025-01-01'],
            'ranking' => ['integer', 'gte:0', 'lte:100'],
            'created_at' => ['date'],
        ];
    }

    public function sortBy(): array
    {
        return ['id', 'name', 'email', 'date_of_birth', 'ranking', 'latestPost.title'];
    }

    public function searchBy(): array
    {
        return ['name', 'email'];
    }

    public function aggregateBy(): array
    {
        return ['name', 'ranking', 'created_at', 'posts', 'posts.status'];
    }

    public function castBy(): array
    {
        return ['ranking'];
    }

    public function castMutator(): array
    {
        return [
            'rankingTier' => [10 => 'bronze', 20 => 'silver'],
        ];
    }

    public function replaceBy(): array
    {
        return [
            'latestPost_title' => 'latestPost.title',
            'latest-post-title' => 'latestPost.title',
            'date-of-birth' => 'date_of_birth',
            'dateOfBirth' => 'date_of_birth',
        ];
    }

    public function defaultSort(): string
    {
        return 'name';
    }
}
```

## Free-text search

`searchBy()` fans a bare query token out across `name` and `email`:

```
GET /api/author?filter=jane
```

matches any author whose `name` or `email` contains `jane`.

## Ranking tiers via cast

`ranking` is a plain integer column (`0`–`100`); `castBy()`/`castMutator()` derive a `rankingTier` label from it without adding a real database column:

```
GET /api/author?cast=ranking:@rankingTier
```

```json
{
  "id": 1,
  "name": "Jane",
  "ranking": 10,
  "casts": {
    "rankingTier": "bronze"
  }
}
```

## Sorting by a `hasOne` relation

`Author::latestPost()` is a `hasOne` relation ordered by `->latest()`; `sortBy()` allows sorting the author list by that related post's title:

```
GET /api/author?sort=latestPost.title
```

`replaceBy()` also exposes it under friendlier keys — `sort=latestPost_title` or `sort=latest-post-title` resolve to the same `latestPost.title` before validation.
