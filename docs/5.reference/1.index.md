# `PaginateQuery` reference

Subclass `Dex\Laravel\Curio\Query\PaginateQuery` and override what you need — everything defaults to "nothing allowed" / empty string:

| Method                          | Returns                                   | Purpose                                                                                                                                 |
|---------------------------------|-------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| `filterBy()`                    | `['field' => 'laravel_validation_rules']` | Allowed filter fields and their validation rules                                                                                        |
| `defaultFilter()`               | `string`                                  | Applied when the request omits `filter`                                                                                                 |
| `maxFilterClauses()`            | `int`                                     | Maximum clauses in one `filter=` string, backed by `config('curio.filter.max_clauses')` — see [Limits](/reference/configuration#limits) |
| `maxFilterDepth()`              | `int`                                     | Maximum relations a filter key may go through, backed by `config('curio.filter.max_depth')`                                             |
| `sortBy()`                      | `['field', ...]`                          | Allowed sort fields                                                                                                                     |
| `allowSort(string ...$columns)` | `static`                                  | Adds sortable fields to one instance, on top of `sortBy()` — for a query built per request                                              |
| `defaultSort()`                 | `string`                                  | Applied when the request omits `sort`                                                                                                   |
| `maxSortFields()`               | `int`                                     | Maximum fields in `sort=`, backed by `config('curio.sort.max_fields')`                                                                  |
| `includeBy()`                   | `['relation' => QueryClass::class]`       | Allowed eager-loads, each linked to its own `PaginateQuery`                                                                             |
| `defaultInclude()`              | `string`                                  | Applied when the request omits `include`                                                                                                |
| `maxIncludeDepth()`             | `int`                                     | Maximum relation nesting depth of one `include=` item, backed by `config('curio.include.max_depth')`                                    |
| `maxIncludeRelations()`         | `int`                                     | Maximum relations in `include=`, backed by `config('curio.include.max_relations')`                                                      |
| `selectBy()`                    | `['field', ...]`                          | Allowed select fields — see [Selecting](/query-string/selecting)                                                                        |
| `defaultSelect()`               | `string`                                  | Applied when the request omits `select`                                                                                                 |
| `aggregateBy()`                 | `['field', ...]`                          | Allowed fields/relations referenceable inside `aggregate` — see [Aggregating](/query-string/aggregating)                                |
| `defaultAggregate()`            | `string`                                  | Applied when the request omits `aggregate`                                                                                              |
| `maxAggregateItems()`           | `int`                                     | Maximum items in `aggregate=`, backed by `config('curio.aggregate.max_items')`                                                          |
| `castBy()`                      | `['field', ...]`                          | Allowed fields referenceable inside `cast` — see [Casting](/query-string/casting)                                                       |
| `castMutator()`                 | `['name' => array\|Collection\|callable]` | Registry of named cast resolvers                                                                                                        |
| `defaultCast()`                 | `string`                                  | Applied when the request omits `cast`                                                                                                   |
| `searchBy()`                    | `['column', ...]`                         | Columns free-text search is fanned out across — see [Free-text search](/query-string/searching)                                         |
| `searchMode()`                  | `string`                                  | `'like'` (default), `'trgm'`, or `'unaccent'` (both Postgres)                                                                           |
| `searchSimilarityThreshold()`   | `float`                                   | Minimum `pg_trgm` similarity score in `trgm` mode (default `0.3`)                                                                       |
| `replaceBy()`                   | `['alias' => 'real_field']`               | Field aliases — applies to `filter`/`sort`/`select`/`aggregate`/`cast`, not `include` — see [Field aliases](/reference/field-aliases)   |
| `defaultPageNumber()`           | `int`                                     | Backed by `config('curio.paginate.default_page_number')`                                                                                |
| `defaultPageSize()`             | `int`                                     | Backed by `config('curio.paginate.default_page_size')`                                                                                  |
| `defaultMaxPageSize()`          | `int`                                     | Backed by `config('curio.paginate.default_max_page_size')`                                                                              |

`PaginateQuery` itself is a thin abstract class composing one trait per method group (`FilterBy`, `SortBy`, `IncludeBy`, `SelectBy`, `AggregateBy`, `CastBy`, `SearchBy`, `ReplaceBy`, `PaginateBy`) — each trait's default implementation returns an empty array/string, which is why an unmodified `extends PaginateQuery` allows nothing.

`getPaginateQuery()` on the request may return an instance instead of a class name, which is what makes `allowSort()` useful — the allow-list can then depend on the request:

```php
public function getPaginateQuery(): string|PaginateQuery
{
    return (new PostQuery())->allowSort('internal_score');
}
```
