# Query string reference

Curio recognizes eight query parameters, each parsed, validated, and applied independently:

| Parameter   | Purpose                                                     |
|-------------|--------------------------------------------------------------|
| `filter`    | [Filtering](/query-string/filtering) rows                    |
| `sort`      | [Sorting](/query-string/sorting) the result set               |
| `include`   | [Eager loading](/query-string/including) relations            |
| `select`    | [Selecting](/query-string/selecting) columns                  |
| `aggregate` | [Aggregating](/query-string/aggregating) (`GROUP BY`/`HAVING`) — mutually exclusive with `select` |
| `cast`      | [Casting](/query-string/casting) result values, post-query    |
| `page`      | [Pagination](/query-string/pagination) — page number          |
| `size`      | [Pagination](/query-string/pagination) — page size             |

Every parameter name above is configurable per application via `config('curio.query.*')` — see [Configuration](/reference/configuration).

Only fields, relations, or columns explicitly declared in the matching `PaginateQuery` method (`filterBy()`, `sortBy()`, `includeBy()`, `aggregateBy()`, `castBy()`) may be referenced — anything else fails validation with a 422.
