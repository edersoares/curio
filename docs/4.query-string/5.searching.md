# Free-text search

Free text tokens in `filter` — anything that doesn't match `key:value` — are collected into a single search against a literal `search` field:

```
filter=laravel php
```

By default this produces nothing, unless the query declares `searchBy()`:

```php
public function searchBy(): array
{
    return ['name', 'email'];
}
```

With `searchBy()` declared, the free text is OR'd across every listed column. The columns have to belong to the model's own table: a relation column (`author.name`) is not joined in, and fails at the database. If `searchBy()` is empty, free text is **silently discarded** rather than causing a validation error.

## Modes

Controlled by `searchMode()` (defaults to `config('curio.search.mode')`, itself defaulting to `'like'`):

| Mode       | Behavior                                                                                                                                                                                                    |
|------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `like`     | Plain `WHERE (column LIKE '%term%' OR column2 LIKE '%term%' ...)`. Works on any database.                                                                                                                   |
| `trgm`     | `WHERE (similarity(unaccent(column), unaccent('term')) > threshold OR ...)`. Requires the Postgres `pg_trgm` and `unaccent` extensions. Accent- and typo-tolerant.                                          |
| `unaccent` | `WHERE (unaccent(lower(column)) LIKE unaccent(lower('%term%')) OR ...)`. Requires the Postgres `unaccent` extension (not `pg_trgm`) — accent-insensitive substring match, no similarity threshold involved. |

Override per query class:

```php
public function searchMode(): string
{
    return 'trgm';
}
```

## Similarity threshold

Only relevant in `trgm` mode. Controlled by `searchSimilarityThreshold()` (defaults to `config('curio.search.similarity_threshold')`, itself `0.3`) — the minimum `pg_trgm` similarity score (`0.0`–`1.0`) for a row to match.

```php
public function searchSimilarityThreshold(): float
{
    return 0.25;
}
```

## Combining with other filters

Free text can be sent alongside normal `key:value` clauses in the same `filter=` string — they combine with `AND`:

```
filter=status:published laravel
```
