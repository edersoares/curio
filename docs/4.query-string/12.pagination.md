# Pagination (`page`, `size`)

`page` (default `1`) and `size` (default `25`) — both configurable per query class or globally.

```
GET /posts?page=2&size=50
```

Requesting a `size` above `defaultMaxPageSize()` (default `250`) fails validation with a 422 — it is **not** silently capped.

## Overriding defaults per query

```php
public function defaultPageSize(): int
{
    return 50;
}

public function defaultMaxPageSize(): int
{
    return 100;
}
```

All three defaults (`defaultPageNumber()`, `defaultPageSize()`, `defaultMaxPageSize()`) are backed by `config('curio.paginate.*')` unless overridden — see [Configuration](/reference/configuration).

The result is a standard Laravel `LengthAwarePaginator`, so anything you'd normally do with one (`->links()` in Blade, `->toArray()`, wrapping in a `ResourceCollection`) works unchanged.
