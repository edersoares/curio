# Presets

Register reusable, named snippets — expanded wherever a free-standing `@name` appears in **any** of the six DSL strings (`filter`, `sort`, `select`, `aggregate`, `include`, `cast`), typically from a service provider's `boot()`:

```php
use Dex\Laravel\Curio\Language\Preset;

Preset::register('active', 'status:active');
Preset::register('vip', '@active plan:premium'); // presets can reference other presets
Preset::register('year', fn (string $year) => "created_at:{$year}-01-01..{$year}-12-31");
```

```
GET /api/authors?filter=@vip @year:2025
```

Register several at once with `Preset::registerMany()`:

```php
Preset::registerMany([
    'active' => 'status:active',
    'vip' => '@active plan:premium',
]);
```

## Behavior

- Referencing a preset that doesn't exist leaves the `@name` token untouched — no error. The token is then read like any other: in `filter=` that means [free text](/query-string/searching) (`@missing` is searched for literally, or discarded when `searchBy()` is empty); in the other parameters it fails validation as an invalid expression.
- A preset that references itself, directly or through another preset, throws an `InvalidArgumentException` **when it's registered**, not when it's expanded. Closure-based presets are exempt from this cycle check.
- Closures can take a parameter, passed after a colon in the query string (`@year:2025` above calls `fn (string $year) => ...` with `'2025'`).
- The package ships one built-in preset, `count`, backing `aggregate=`'s bare `@count` shorthand (it expands `@count` to `*:@count`, and `@count:@join` to `*:@count:@join` — see [Aggregating](/query-string/aggregating)). `Preset::clear()` resets your own registered presets but leaves this one in place.

## Full API

`Dex\Laravel\Curio\Language\Preset` is a static registry:

| Method                                            | Purpose                                                            |
|---------------------------------------------------|--------------------------------------------------------------------|
| `register(string $name, string\|Closure $filter)` | Register a single preset                                           |
| `registerMany(array $presets)`                    | Register several at once                                           |
| `get(string $name)`                               | Retrieve a registered preset                                       |
| `all()`                                           | All registered presets                                             |
| `has(string $name)`                               | Whether a preset is registered                                     |
| `clear()`                                         | Remove all registered presets (useful in tests)                    |
| `expand(string $filter)`                          | Recursively expand `@name`/`@name:param` tokens in a filter string |
