# Casting (`cast`)

`cast` runs an arbitrary, named PHP transform against a field's already-hydrated value — after `$builder->paginate()` has executed, not as part of the SQL query. This is different from every other parameter on this page: `filter`/`sort`/`include`/`select`/`aggregate` all build SQL, while `cast` runs pure PHP (array/`Collection` lookups, or a callable) once results are in memory.

```
cast=field:@castName[:@alias(name)]
```

## Declaring casts

```php
public function castBy(): array
{
    return ['ranking'];
}

public function castMutator(): array
{
    return [
        'rankingTier' => [10 => 'bronze', 20 => 'silver'],
    ];
}
```

`castBy()` lists which **fields** may be cast; `castMutator()` is the registry of named **resolvers** available to apply. A `cast=` item references both: the field to read, and which registered resolver to run against its value.

```
GET /api/authors?cast=ranking:@rankingTier
```

## Resolver types

A resolver in `castMutator()` can be:

- **An array** — a plain lookup keyed by the field's raw value: `[10 => 'bronze', 20 => 'silver']`. A value that isn't a key in the array falls back to the original, unmodified value.
- **An `Illuminate\Support\Collection`** — same lookup semantics as an array, via `Collection::get($key, $default)`.
- **A callable** — `fn (mixed $value): mixed`, run directly against the field's value with no fallback behavior of its own.

```php
public function castMutator(): array
{
    return [
        'rankingTier' => [10 => 'bronze', 20 => 'silver'],       // array lookup
        'rankingLabel' => collect([10 => 'Bronze', 20 => 'Silver']), // Collection lookup
        'isTopRanked' => fn (mixed $ranking): bool => (int) $ranking >= 90, // callable
    ];
}
```

## Aliasing

`cast=ranking:@rankingTier:@alias(tier)` renames the output key from `rankingTier` to `tier`.

## Where the result lands

Cast results are **never** written to the field's own attribute. Instead, every `cast=` item in a single request is collected into one `casts` attribute on each model, keyed by the field name (or `:@alias(name)` when given):

```json
{
  "id": 1,
  "name": "Jane",
  "ranking": 10,
  "casts": {
    "rankingTier": "bronze"
  }
}
```

This keeps the original column value intact in the response while surfacing the derived value alongside it. See [API resources](/reference/api-resources) for how `AggregateResource::casts()` reads this attribute.
