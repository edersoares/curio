# Sorting (`sort`)

Space-separated field list, prefix `-` for descending:

```
sort=-published_at title
```

Only fields declared in `sortBy()` are allowed. Sorting by a related model's column (`author.name`) is supported for `BelongsTo`/`HasOne` relations and is applied via an automatic `JOIN`.

```php
public function sortBy(): array
{
    return ['id', 'title', 'published_at', 'author.name'];
}
```

## Field aliases

`sort` keys are resolved through the query's [`replaceBy()`](/reference/field-aliases) map before validation — the same alias map used by `filter`, `select`, `aggregate`, and `cast`.

## The `:@unaccent` modifier

Add `:@unaccent` to an individual field to order by `unaccent(lower(column))` instead of the plain column — Postgres only, requires the `unaccent` extension:

```
sort=email:@unaccent
sort=-email:@unaccent ranking
```

This is per-field, not a global setting — only the field carrying `:@unaccent` is affected; other fields in the same `sort=` string sort normally. There's no query-class-level override for this — it's opted into per request, per field.
