# Installation

```bash
composer require dex/curio
```

The package auto-registers `Dex\Laravel\Curio\Providers\CurioServiceProvider`. No further setup is required — sensible defaults are merged from `config/curio.php`.

To override any default, create your own `config/curio.php` in the app with just the keys you want to change — the package's defaults are merged in for the rest. There's no `vendor:publish` step; the file simply needs to exist at that path.

See [Configuration](/reference/configuration) for the full list of keys.
