# Testing

```bash
composer test                  # run all tests
vendor/bin/pest tests/path/to/Test.php --filter "test name"  # run a single test
composer analyse               # PHPStan static analysis (level max, src/ and config/)
composer format                # Laravel Pint code style
composer coverage               # test coverage with Xdebug
```

The `workbench/` directory is a runnable Orchestra Testbench app (`Author`, `Post`, `Comment`, `User` models with matching queries, requests, controllers and resources) used by the test suite — it's a good place to see the full feature set wired together end-to-end, and is the source for every example in the [cookbook](/cookbook).

Tests are organized to mirror the source: `tests/UseCase/*Test.php` covers each `Language` parser/validator individually (`Filtering`, `Sorting`, `Selecting`, `Aggregating`, `Casting`, `Including`, `Searching`, `Parser`, `VariableResolver`), and `tests/Extensions/PaginatorTest.php` covers the end-to-end HTTP/`Paginator` pipeline. `tests/CoverageTest.php` and `tests/ArchTest.php` sit at the root, covering coverage gaps and architectural rules respectively.
